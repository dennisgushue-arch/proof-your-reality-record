# Week 1 Asset Manifest (Film Once, Reuse Across 7 Posts)

Brand: **Proof Your Reality Record**  
Scope: **Week 1 posts (2026-06-25 to 2026-07-01)**  
Goal: Minimize production effort by capturing core footage once and repurposing it across all scheduled assets.

---

## Production Strategy in One Line

Capture **master modular footage once** (A-roll + app UI + utility b-roll), then assemble daily deliverables with different hooks, text overlays, and CTAs.

---

## Asset Taxonomy

- **MSTR** = Master clip (film once)
- **DRV** = Derived/edit variation (reuse from master)
- **UNQ** = Unique pickup required for a specific day/post

## 5) Shoot Order (Fewest Takes Plan)

1. **Block A (Creator A-roll, 45 min)**
   - Capture MSTR-A01 to A05 in one wardrobe/setup.
2. **Block B (App screen records, 40 min)**
   - Capture MSTR-S01 to S08 in one uninterrupted session.
3. **Block C (Utility b-roll, 30 min)**
   - Capture MSTR-B01 to B08 in one lighting setup.
4. **Block D (Unique pickups, 25 min)**
   - Capture only UNQ items.
5. **Post templates (30 min setup + reuse)**
   - Build DRV templates once, apply to all exports.

Estimated total production time: **~2.5 to 3.0 hours** for all Week 1 outputs.

## 6) File Naming + Folder Structure

### Naming Convention

`WK1_<DAY>_<ASSET-ID>_<DESC>_v01.mp4`

Examples:

- `WK1_D1_MSTR-S01_open-app-create-incident_v01.mp4`
- `WK1_D4_UNQ-04-01_3-mistakes-direct-line_v01.mp4`

### Suggested Folders

- `production/week1/raw/a-roll/`
- `production/week1/raw/screen-recordings/`
- `production/week1/raw/b-roll/`
- `production/week1/derived/templates/`
- `production/week1/exports/day1..day7/`
