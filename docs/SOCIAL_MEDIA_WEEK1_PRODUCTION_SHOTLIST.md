# Week 1 Production-Ready Shot List Pack (Days 1–7)

<!-- markdownlint-disable MD024 -->

Brand: **Proof Your Reality Record**  
Production Window: **2026-06-25 to 2026-07-01**  
Purpose: Give creator + editor a ready-to-execute brief with scene-by-scene scripts, on-screen text, and b-roll.

---

## Quick Production Specs

- Aspect ratio: **9:16** (1080 x 1920)
- Captions: burned in (high contrast)
- Safe zone: keep key text in center 80%
- Target duration:
  - Reels/TikTok shorts: **15–25s**
  - Stories frame timing: **5–7s/frame**
- Audio: clean voiceover + low, calm bed music
- Product capture: use real app flow when possible (dashboard, incident capture, timeline, Prepare Me, export)
- Compliance footer where relevant: **“Not legal advice. Documentation support only.”**

## Week 1 Batch Shooting Plan (Recommended)

- **Shoot day:** Record all creator-to-camera A-roll in one session (45–60 min).
- **Screen capture day:** Capture all app UI flows in one session (30–45 min).
- **Edit pass 1:** Assemble rough cuts + text overlays.
- **Edit pass 2:** Add captions, sound leveling, and CTA end cards.
- **Export:**
  - Master: 1080x1920 H.264, 15–25 Mbps
  - Audio: AAC, 48 kHz
