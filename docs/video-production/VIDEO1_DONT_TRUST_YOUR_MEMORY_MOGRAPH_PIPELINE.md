# Video 1 — Motion-Graphics Pipeline (Cinematic Premium)

Purpose: execution-ready checklist for editor/animator to produce a premium ad without live filming.

---

## Tool-Agnostic Build Order

1. Build dark premium scene backgrounds (5 scenes).
2. Import Proof UI screens and convert to layered mockup assets.
3. Animate camera paths per scene timing.
4. Add text overlays + subtitle pass.
5. Layer SFX and cinematic music bed.
6. Record/place professional VO.
7. Final color polish, audio mastering, and export.

---

## Scene-by-Scene Animation Cues

### 0:00–0:03 — Memory Fracture Intro

- Background: dark gradient + floating particles.
- Elements: message fragments drifting and fading.
- Camera: dolly-in, slight clockwise roll (<2°).
- Text: **STOP TRUSTING YOUR MEMORY** (instant, high contrast).

### 0:03–0:08 — Buried Evidence

- Background: deeper contrast with subtle vignette.
- Elements: screenshot cards stack downward rapidly.
- Camera: orbital pass around floating phone mockup.
- FX: motion blur trails, low-opacity grain.

### 0:08–0:14 — Start Live Incident

- Background: clean premium stage with soft spotlight.
- Elements: Proof app UI hero reveal.
- Camera: top-down to perspective tilt reveal.
- FX: tap pulse ring on **Start Live Incident**.

### 0:14–0:22 — Unified Timeline Build

- Background: layered depth field with subtle glow.
- Elements: Photo/Voice/Notes cards snap into timeline rail.
- Camera: lateral tracking shot + parallax.
- FX: timestamp chips populate sequentially.

### 0:22–0:30 — Confidence End State

- Background: low-noise dark hero backdrop.
- Elements: dashboard timeline + contradiction alert card.
- Camera: slow push-in and settle center.
- Text: **Lock the facts before memory changes** (hold final 1.8–2.0s).

---

## Audio Build Sheet

### Voiceover

- Use pro VO talent (neutral North American English, trustworthy tone).
- Keep pacing steady; avoid theatrical emphasis.

### SFX Palette (Subtle)

- UI tap clicks (soft, short tail)
- Swipe/whoosh transitions (low brightness)
- Card settle ticks (light thump)
- Alert pulse (restrained, non-alarming)

### Music

- Genre: cinematic tech ambient
- BPM feel: 70–90 (or half-time equivalent)
- Energy curve: low-intensity intro → slight lift at Scene 3 → confident close
- Keep music under VO by default; duck further during key lines

---

## UI Mockup Requirements

- Use high-resolution Proof UI captures at native aspect where possible.
- Keep all UI text legible on mobile screens.
- Apply corner radius and subtle shadow consistently.
- Maintain realistic interaction timing (tap, load, insert).
